# How to Create an Advisor Guide

## What You Need

- Access to the **Advisor_Guide_Tool** folder shared by Rodrigo in Dropbox and then synced to your local folders
- **Claude Code** with Cowork
- A **Notion** page for team editing
- Your source materials (articles, notes, talking points - whatever you have)

## Steps

### 1. Start a Session in Claude

Open the Advisor_Guide_Tool folder in Claude Code and type:

**"Create a new advisor guide"**

Claude will walk you through a few quick questions:
- Which brand line? (ETFs US, ETFs Canada, Funds, or Portfolio Solutions)
- What's the topic?
- Standard banner or custom cover image?
- Will you need any charts or images?
- What source materials are you working from?

### 2. Write the Content with Claude

Provide your source materials and work with Claude to draft the guide. Claude will write in the established Advisor Guide voice and style. Go back and forth until you're happy with the text.

### 3. Move to Notion for Team Review

When the draft is ready, Claude will give you a clean Markdown version of the full guide. Copy and paste it into a Notion page, then share with the team for editing.

During the Notion phase, the team can:
- Edit any text directly
- Add or remove sections
- Drop in chart images where the placeholders are marked

### 4. Exporting Charts from Excel as SVG

If the guide includes charts or graphs created in Excel:

1. **Right-click** on the chart in Excel
2. Select **Save as Picture...**
3. Change the file type to **Scalable Vector Graphics (.svg)**
4. Save the file

Drop the SVG files into the Notion page where they belong. SVG images are vector-based, so they'll look sharp at any size in the final document.

### 5. Generate the Final Document

Once the team is done editing in Notion:

1. Copy all the text from the Notion page
2. Go back to Claude and paste it in
3. Drag and drop any SVG image files into the chat
4. Claude will generate the branded HTML file

Your generated file will be in: **Advisor_Guide_Tool -> generator -> output**

Open the HTML file in your browser to review it. When you're happy with the result:

1. **File -> Print -> Save as PDF** to create the final PDF
2. Review the PDF to confirm everything looks correct

### 6. Designer Handoff (if needed)

If the guide needs a final production polish or additional design elements, send the **PDF** to Emi (our designer). The PDF preserves exact layout, embedded fonts, and vector-quality text that can be refined in Adobe Illustrator or other design tools.
