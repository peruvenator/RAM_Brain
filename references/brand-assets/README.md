# Brand Assets Index

All projects reference brand assets via relative paths from their project folder (e.g., `../../references/brand-assets/return-stacked/`). Never copy brand files into a project folder.

## Return Stacked (`return-stacked/`)

### Color Palette

| Token | Hex | Usage |
|-------|-----|-------|
| Text Primary | `#2c3641` | Body text, headings |
| Text Secondary | `#625c6d` | Supporting text, chart labels |
| Cover Dark | `#172c3a` | Cover banner, dark panels |
| Section Gray | `#f0f1f1` | Light gray section backgrounds |
| White | `#ffffff` | Text on dark backgrounds, card overlays |
| Border Gray | `#bfbfbf` | Table borders, dividers |
| Teal Primary | `#14cfa6` | Callouts, highlights, accents |
| Teal Light | `#a1d7c6` | Decorative watermark text |
| Blue Secondary | `#3a6a9c` | Links, secondary accents |
| Blue Light | `#7da5ce` | Chart elements |
| Yellow | `#ebe96a` | Sparingly, for highlights |

### Font

All projects use **DM Sans** (Google Fonts). Weights: Thin (100) through ExtraBold (800), each with italic. Files are `.ttf` in `Font_Family/`.
