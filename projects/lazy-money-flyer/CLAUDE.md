# Lazy Money Flyer

## Overview

2-page print flyer for the **ReSolve Asset Management "Lazy Money" Separately Managed Account** service. Distributed at the Family Office Summit in Toronto. Target audience: family offices, UHNW individuals, small institutions.

## Key Files

| File | Purpose |
|------|---------|
| `chart_exports/annual_returns.png` | Recreated grouped bar chart (matplotlib, RAM brand) |
| `chart_exports/correlation_heatmap.png` | Recreated correlation heatmap (matplotlib, RAM brand) |
| `chart_exports/` | All chart image exports |
| Source PPTX | `../../Downloads RG/RAM Lazy money flyer content.pptx` (10 slides) |

## Brand

Uses **ReSolve Asset Management** brand identity (not Return Stacked):
- Font: Helvetica Neue LT Std (`../../references/brand-assets/resolve-am/Fonts/`)
- Matplotlib style: `../../references/brand-assets/resolve-am/matplotlib/resolve.mplstyle`
- Colors: `../../references/brand-assets/resolve-am/Brand Colours.txt`
- Logo: `../../references/brand-assets/resolve-am/Logo/`
- Primary: `#00478D` (dark blue), Accent: `#FBBA00` (amber)

## Content Structure (2 pages)

### Page 1 -- What & Why
- What is return stacking (capital-efficient strategy)
- Why ReSolve (portable alpha for mid-market)
- Portfolio enhancement diagram
- Jonathan Glidden (CIO, Delta Airlines) pull quote

### Page 2 -- Proof & CTA
- Carry case study: annual returns bar chart + correlation heatmap
- Stats table (Return, Volatility, Max DD, Sharpe)
- Institutional credibility list
- Contact CTA + condensed disclosures

Final design produced in Canva (US Letter, print-ready).
