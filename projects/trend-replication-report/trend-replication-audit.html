2. Return Methodology

Daily Returns

Daily returns are computed via simple percentage change on the raw index level:

for col in ['SG_Trend', 'TD_Small', 'TD_Med', 'BU', 'Blend']:
    df[f'{{col}}_ret'] = df[col].pct_change()
df = df.dropna(subset=['SG_Trend_ret']).reset_index(drop=True)

This is equivalent to: rt = (Pt / Pt-1) - 1. The first row is dropped (NaN from pct_change).

Growth of $1

Each series is normalized to $1 at the first observation (after dropna):

for col in ['SG_Trend', 'TD_Small', 'TD_Med', 'BU', 'Blend']:
    df[f'{{col}}_g1'] = df[col] / df[col].iloc[0]

G1t = Levelt / Level0. This preserves the exact return characteristics of the original series.

Monthly Returns

Monthly returns use end-of-month resampling and percentage change on levels:

df_m = df.set_index('Date').resample('ME').last()
for col in ['SG_Trend', 'TD_Small', 'TD_Med', 'BU', 'Blend']:
    df_m[f'{{col}}_mret'] = df_m[col].pct_change()
df_m = df_m.dropna(subset=['SG_Trend_mret'])

Quarterly Returns

Quarterly returns follow the same pattern with 'QE' resampling.

Annual Returns

Annual returns are calculated within each calendar year as: (last trading day level / first trading day level) - 1. Partial years (first and last) are marked with an asterisk.

Annualized Return

Compound annual growth rate using calendar days:

n_days = (df['Date'].iloc[-1] - df['Date'].iloc[0]).days
ann_ret = ((1 + cum_ret/100) ** (365.25/n_days) - 1) * 100

4. Lo (2002) Autocorrelation Adjustment -- Detailed Decomposition

The Formula

The Lo (2002) adjustment factor eta accounts for serial correlation in daily tracking differences when annualizing volatility. The standard sqrt(252) annualization implicitly assumes i.i.d. returns; when autocorrelation is present, the effective annualized dispersion differs.

The adjustment factor is:

eta = 1 + 2 x Σk=1q (1 - k / (q + 1)) x rhok

Where:

  • q = 21 lags (approximately 1 month of trading days)
  • rhok = autocorrelation of the demeaned tracking difference at lag k, computed via np.corrcoef(x_dm[k:], x_dm[:-k])[0,1]
  • The kernel weight (1 - k/(q+1)) is the Bartlett (triangular) kernel, giving decreasing weight to higher lags
  • A floor of 0.01 is applied: eta = max(eta, 0.01) to avoid degenerate/negative values

The Lo-adjusted tracking error is then:

TEadj = sigmadaily x sqrt(252 x eta) x 100

When eta < 1 (negative net autocorrelation), the standard TE overstates true longer-horizon dispersion.

Source Code: lo_eta()

def lo_eta(x, q):
    """Compute the Lo (2002) autocorrelation adjustment factor."""
    x_dm = x - x.mean()
    eta = 1.0
    for k in range(1, q + 1):
        rho_k = np.corrcoef(x_dm[k:], x_dm[:-k])[0, 1]
        eta += 2 * (1 - k / (q + 1)) * rho_k
    return max(eta, 0.01)  # floor to avoid degenerate cases

Source Code: lo_adj_te()

def lo_adj_te(diff):
    """Lo-adjusted annualized TE for an arbitrary daily difference series."""
    daily_std = np.std(diff, ddof=1)
    eta = lo_eta(diff, LO_Q)
    return daily_std * np.sqrt(252 * eta) * 100
