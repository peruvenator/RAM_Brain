# Trend Replication Report

3-year trend replication analysis for the SocGen CTA and related trend indices.

## Key Files

- `trend-data.csv` -- Daily time series data (from Feb 2023 onwards)
- `analysis.py` -- Data analysis script
- `build_report_v2.py` -- Report generation script
- `trend-replication-analysis.html` -- Generated HTML report

## Usage

```bash
python analysis.py
python build_report_v2.py
```
