# AI Tool Compliance Assessment

Generates compliance assessment reports for AI tools used at ReSolve.

## Key Files

- `generate_assessment.py` -- Main script to generate assessments
- `Templates/` -- Word document templates for reports
- `Reports_Generated/` -- Output directory (not git-tracked)
- `*_config.json` -- Tool-specific configuration files (Claude Code, Gemini, Grok)

## Usage

```bash
python generate_assessment.py
```
