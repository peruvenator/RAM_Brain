## How to use this KB

1. **For lineup-wide lookup or comparison:** start with `overview.md`.
2. **For a specific product:** open the file under `etfs-us/`, `etfs-canada/`, `mutual-funds/`, or `partner-funds/`. Each fund file contains: at-a-glance facts → investment case → mechanics → FAQs → pitch language (verbatim) → compliance notes.
3. **For framework / concept-level explanations** (return stacking, trend replication, carry, merger arb): open `concepts/`.
4. **For sponsor / advisor structure** (compliance-relevant): see end of `overview.md`.
5. **For refresh cadence:** see `update-process.md`.

## Source-of-truth conventions

Primary sources, in order of authority:
1. Product page on `returnstackedetfs.com`, `returnstackedetfs.ca`, `returnstackedfunds.com`, or `quantifyfunds.com`
2. Product factsheet PDF
3. Product brief PDF
4. Summary prospectus
5. Full prospectus

**Time-sensitive (verify before publishing):** performance, NAV, AUM, holdings, risk allocations.
**Stable (treat as authoritative):** ticker, CUSIP, inception date, wrapper, jurisdiction, sub-adviser arrangements.

Marketing copy in "pitch language" sections is preserved verbatim from product pages so it can be reused without re-deriving compliance-approved phrasing.
