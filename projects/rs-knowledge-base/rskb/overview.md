## How to think about the lineup

The Return Stacked® lineup follows a deliberate matrix structure — a **base exposure** stacked with a **diversifying alternative**. Naming convention:

```
"RS" + [base asset code] + [stack strategy code]
       ├ S = U.S. Stocks                ├ T = Trend (Managed Futures)
       ├ B = U.S. Bonds                 ├ Y = Yield (Carry)
       └ S = Global Stocks (RSSB only)  ├ A = Arbitrage (Merger Arb)
                                         ├ X = Gold/Bitcoin
                                         └ B = Bonds (RSSB)
```

So:
- **RSST** = Stocks + Trend
- **RSBT** = Bonds + Trend
- **RSSY** = Stocks + Yield
- **RSBY** = Bonds + Yield
- **RSBA** = Bonds + Arbitrage
- **RSSX** = Stocks + Gold/Bitcoin
- **RSSB** = Stocks + Bonds (the unique "core capital-efficient" product)
- **RGBM / RGBM.U** = Canadian "Global Balanced + Macro"
- **RDMIX** = U.S. mutual fund "Balanced + Macro"

## RSSB plays a strategically different role

RSSB is the **capital-efficient core** of the lineup. While the other Stacks add a *diversifier* on top of one core asset class, RSSB delivers $1 stocks + $1 bonds — the **traditional 60/40 building blocks themselves** in a single ticker. This frees up balance-sheet space for advisors to layer the diversifying Stacks on top within the same client account, achieving the full "double stack" that institutional portable-alpha portfolios have used for decades.

## Cross-suite themes for content writing

When discussing the lineup as a whole, these recurring threads work:
1. **Capital efficiency** — every dollar does double duty; $1 invested = $2 of exposure.
2. **Diversification without sacrifice** — diversifiers added *on top* of core exposure, not in place of it.
3. **Institutional technique, retail wrapper** — concepts going back to the 1980s, packaged in daily-liquid ETFs.
4. **Built to diversify, not displace** — frames each Stack as additive to a traditional 60/40 rather than a replacement.
5. **Refuse to choose** — reject the false dichotomy of "core vs. alternatives".
