# All Terrain Q&A

Knowledge base and Q&A workspace for the ReSolve All Terrain strategy.

## Purpose

This project is the single place to:
- Drop strategy documents, pitch decks, fact sheets, performance data, and other context
- Ask investor-facing and internal questions about the strategy
- Draft and refine answers that can be used in investor communications, DDQs, and conversations

## Context Files

Drop any All Terrain reference material into `context/`. This includes:
- Strategy overviews, pitch decks, one-pagers
- Performance reports, tear sheets, fact sheets
- DDQ responses (past)
- Internal research papers or commentary
- Regulatory/legal documents (OM, PPM)
- Email threads or notes from investor conversations

When you start a session, say "read the context" and I'll load the relevant files before answering questions.

## Q&A Sessions

Answered questions are saved in `qa/` as markdown files for future reference.

File naming: `YYYY-MM-DD-topic-slug.md`

Each file includes:
- The question(s) asked
- The answer drafted
- Source citations where applicable (pointing to context files)
- Status: Draft / Reviewed / Approved

## How to Use

1. Drop files into `context/` before asking questions
2. Start a session: "Let's work on All Terrain Q&A" or just ask a question
3. I'll read the context, draft an answer, and ask if you want to save it
4. Saved answers build up a reusable library for DDQs and investor conversations

## Audience

Answers should be calibrated for sophisticated institutional allocators and family offices -- not retail. Assume the reader understands liquid alternatives, managed futures, and risk-adjusted return concepts.

## Tone

Professional, precise, no fluff. Quantitative where possible. Honest about risks and limitations.
